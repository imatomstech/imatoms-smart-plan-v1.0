Apps Script — Backup ขึ้น Drive + Email แจ้งเตือน
เชื่อมทาง Google Apps Script — ตั้งค่าครั้งเดียว จากนั้นไฟล์ Backup จะอัปโหลดขึ้น Drive ให้อัตโนมัติทุกครั้ง ไม่ต้อง Login ซ้ำ ไม่มีวันหมดอายุ
⚪ ยังไม่ได้ตั้งค่า Web App URL
Apps Script Web App URL (ตั้งค่าครั้งเดียว)
1. Login Google ด้วย imatomsapps1976@gmail.com → ไปที่ script.google.com → New project
2. กดปุ่ม "📋 Copy โค้ด" ด้านล่าง → วางแทนโค้ดเดิม → Save
3. เลือกฟังก์ชัน setup → Run → Authorize (Advanced → Go to … (unsafe) → Allow) — ระบบสร้างโฟลเดอร์ Backup, Google Sheet และ Trigger แจ้งเตือนให้อัตโนมัติ
4. Deploy → New deployment → ⚙️ Web app → Execute as = Me, Who has access = Anyone → Deploy
5. คัดลอก Web app URL (ลงท้าย /exec) → วางในช่องด้านบน → กด "บันทึก"
💡 URL เดียวกันนี้ใช้กับ อีเมลแจ้งเตือน ในหน้า 🗓️ Schedule Work ด้วย — ไฟล์ Backup จะเก็บในโฟลเดอร์ "iMATOMs sMART pLAN Backup" บน Drive
✅ วิธีที่แนะนำ (ปลอดภัยสำหรับเครื่องบริษัท ไม่ต้องติดตั้งอะไร)
1. กดปุ่ม 💾 Backup ด่วน ที่มุมซ้ายล่าง → ไฟล์ .json จะดาวน์โหลดเข้า Downloads
2. เปิดเว็บ drive.google.com → Login ด้วยบัญชี imatomsapps1976@gmail.com
3. เปิดโฟลเดอร์ "iMATOMs sMART pLAN Backup"
4. ลากไฟล์ .json จาก Downloads มาวางในหน้าเว็บ Drive ได้เลย (ใช้เวลา ~10 วินาที)
💡 หมายเหตุ: มีวิธี sync อัตโนมัติเต็มรูปแบบผ่าน "Google Drive for Desktop" แต่ต้องติดตั้งโปรแกรมบนเครื่อง — ถ้าเป็นเครื่องบริษัท แนะนำสอบถาม IT ก่อน หรือใช้วิธี Manual ด้านบนแทนได้เลย ปลอดภัยกว่าและไม่ต้องขอสิทธิ์ Admin
